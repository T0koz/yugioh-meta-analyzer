# 0033 — Front : toujours le modèle le plus puissant disponible

- Date : 2026-11-16
- Statut : acceptée
- Décidé par : Thomas
- Tickets : TOK-94

## Contexte
Les sessions de travail peuvent tourner sur des modèles de coût différent.

## Options
- Modèle économique partout
- Modèle le plus puissant pour le front, économique pour données, doc et tâches mécaniques

## Décision
Le front utilise toujours le modèle le plus puissant (Fable, sinon Opus) ; le modèle économique est réservé aux données, à la doc et aux tâches mécaniques.

## Raison
Rendu visuel « au top » (`CLAUDE.md`). Coût : consommation d'usage plus élevée.

## Conséquences
Inscrit dans `CLAUDE.md` et `regles.md` ; l'orchestrateur note le modèle réellement utilisé dans `etat.md`.
