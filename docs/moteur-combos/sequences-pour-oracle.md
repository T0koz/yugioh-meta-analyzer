# Séquences de combos à rejouer dans l'oracle (TOK-140, jalon n°5)

23 séquences distinctes, 10 combos.

> **18/11/2026**, généré par `scripts/combos_export_oracle.py` depuis la sortie de `scripts/combos_j2.py`. Pour la session de l'oracle (jalon n°6, isolée) : chaque séquence est écrite dans le langage des règles, sans référence au code du moteur. **À vérifier dans l'oracle** : (1) chaque action est légale à son moment, avec les coûts et choix indiqués ; (2) les déplacements de cartes sont ceux qu'écrit l'oracle ; (3) le plateau final est le même. Combos et sources : `combos-guides.md` (G1-G5 lot C3, G6-G10 lot J2 plein). Statut : **non vérifié** tant que l'oracle n'a pas rejoué.

Conventions : les cartes de réponse (Ash Blossom, Ghost Ogre, Droll & Lock Bird, Mulcharmy Fuwalos) ne sont jamais activées (filtre déclaré) ; le joueur ne répond pas à ses propres maillons ; un monstre venu de l'Extra Deck va en Zone Monstre Extra si elle est libre. Une séquence identique à une autre n'est écrite qu'une fois.
