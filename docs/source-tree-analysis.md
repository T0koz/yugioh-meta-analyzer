# Source Tree Analysis — Yu-Gi-Oh! Meta Analyzer

## Repository Structure

```
yugioh-meta-analyzer/          # Project root
│
├── app.py                     # ← ENTRY POINT: Streamlit dashboard (9 pages)
├── run.sh                     # Convenience launcher: source .venv + streamlit run app.py
│
├── scripts/                   # ETL & maintenance scripts (run manually or via cron)
│   ├── fetch_cards.py         # YGOPRODeck API → data/raw/cards.json (13,797 cards)
│   ├── init_db.py             # cards.json → yugioh.db (cards + card_sets + card_prices + images)
│   ├── fetch_tournament_decks.py  # yugiohmeta.com TCG → tournament_decks, deck_cards
│   ├── fetch_ocg_decks.py     # yugiohmeta.com OCG → tournament_decks (ocg=1), deck_cards
│   ├── snapshot_prices.py     # ← CRON 09:00: bulk price fetch → card_price_history
│   ├── setup_impact_tables.py # Generates ban_impact + card_impact from existing tables
│   └── explore_limitless.py   # Playwright diagnostic tool (not part of main pipeline)
│
├── notebooks/                 # Analysis pipeline — execute in order to rebuild all DB tables
│   ├── 01_exploration.ipynb   # Initial data exploration (read-only, no DB writes)
│   ├── 02_cooccurrence.ipynb  # Co-occurrence (6 variants) + K-Means clustering
│   ├── 03_graph.ipynb         # NetworkX graph + Louvain communities + centrality
│   ├── 04_meta_score.ipynb    # Meta scoring + trend analysis + tier list scraping
│   ├── 05_meta_prediction.ipynb  # ML prediction: Ridge + AR(1) + Naïf blend
│   ├── 06_card_ban_impact.ipynb  # Bridge score + ban impact analysis
│   ├── 07_nlp_text_synergies.ipynb  # NLP: TF-IDF + mechanical tags on card text
│   ├── 08_nlp_combos.ipynb    # NLP: YouTube transcript combo extraction
│   ├── 09_banlist_history.ipynb   # Scraping Yugipedia → banlist_history + features
│   ├── 09_ocg_tcg_correlation.ipynb  # Pearson correlation + lag analysis (read-only)
│   ├── 10_archetypes_official.ipynb  # YGOPRODeck archetypes.php → mapping tables
│   ├── 10_boutique_alert_score.ipynb  # Boutique signal + TCG compat filter
│   ├── 11_early_card_signal.ipynb    # Early signal for new cards
│   └── 12_deck_clustering.ipynb      # K-Means deck style clustering
│
├── data/                      # Data storage (gitignored: *.db, raw/)
│   ├── yugioh.db              # ← MAIN DATABASE: SQLite ~236 MB (gitignored)
│   ├── serving.db             # ← API subset, ~9 MB, generated (gitignored)
│   ├── raw/
│   │   └── cards.json         # ~31 MB, 13,797 cards (gitignored)
│   ├── graph_maliss.html      # Interactive Pyvis graph — Maliss archetype
│   ├── graph_tenpai.html      # Interactive Pyvis graph — Tenpai Dragon
│   ├── graph_ryzeal.html      # Interactive Pyvis graph — Ryzeal
│   ├── graph_branded.html     # Interactive Pyvis graph — Branded
│   └── SOURCES.md             # Data source documentation
│
├── lib/                       # Frontend visualization libraries (vendored)
│   ├── bindings/              # Pyvis JS bindings
│   ├── tom-select/            # Tom Select JS (dropdown component)
│   └── vis-9.1.2/             # vis-network JS library (graph rendering in Streamlit)
│
├── docs/                      # BMad documentation (this folder)
│   ├── index.md               # Master documentation index
│   ├── project-overview.md    # Executive summary + metrics
│   ├── architecture.md        # Technical architecture + algorithms
│   ├── data-models.md         # Complete SQLite schema (36 tables)
│   ├── source-tree-analysis.md  # This file
│   ├── development-guide.md   # Setup + rebuild + run instructions
│   └── project-scan-report.json  # BMad workflow state
│
├── _bmad/                     # BMad framework internals (generated by installer)
├── _bmad-output/              # BMad planning artifacts output
├── design-artifacts/          # UI/UX design files
│
├── context.md                 # ← KEY FILE: Full technical context (read before coding)
├── README.md                  # Project overview
├── BACKLOG.md                 # Feature backlog (TOK-5 to TOK-45, all done except TOK-31→37)
│
├── .claude/                   # Claude Code configuration
│   └── settings.local.json    # Local permissions
│
└── .venv/                     # Python virtual environment (gitignored)
```

## Critical Entry Points

| Entry Point | Command | Purpose |
|-------------|---------|---------|
| `app.py` | `streamlit run app.py` | Launch dashboard |
| `run.sh` | `bash run.sh` | Launch dashboard (handles venv) |
| `scripts/snapshot_prices.py` | Cron 09:00 daily | Price history update |
| `notebooks/02_cooccurrence.ipynb` | Jupyter | Most complex notebook (all co-occurrence variants) |
| `notebooks/05_meta_prediction.ipynb` | Jupyter | ML pipeline |
